PEZHWAN · Passwordless

Magic-link sign-in with a simulated inbox — no passwords involved.

How this demo works: with a real email provider, "send magic link" emails the user a clickable link; clicking it redeems the token and signs them in. Here there is no inbox, so the server prints the one-time token to its console and you paste it below. Unknown email addresses receive a decoy token intentionally — the API answers identically either way so address enumeration is not possible. Decoys never redeem, so an unknown address simply can't sign in.
